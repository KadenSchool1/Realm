## About

Realm is a Next.js-based web browser that utilizes free search proxies for enhanced privacy and accessibility. Built with modern web technologies including TypeScript, React, and Tailwind CSS.

## Features

- 🔒 Privacy-focused with free search proxies
- ⚡ Built with Next.js for optimal performance
- 🎨 Modern UI with Tailwind CSS
- 📱 Responsive design
- 🚀 Deployed on Vercel

## Tech Stack

- **Frontend**: React 18, TypeScript, Tailwind CSS
- **Framework**: Next.js 14
- **Deployment**: Vercel

## Getting Started

### Prerequisites

- Node.js 18+
- npm or yarn

### Installation

```bash
git clone https://github.com/KadenSchool1/Realm.git
cd Realm
npm install
```

### Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Build & Deploy

```bash
npm run build
npm run start
```
